## 与众不同之处

### 1. 資料模型 驱动，而非表单/表格驱动
NocoBase 采用 資料模型驱动 的方式，将資料结构与使用者介面分离，突破了传统表单或表格驱动开发的限制，釋放無限可能。

- 介面与資料结构彻底解耦
- 同一个表或記錄可以建立任意數量、任意形式的区块和操作
- 支持主資料程式庫、外部資料程式庫以及第三方 API 作为資料源

![model](https://static-docs.nocobase.com/model.png)

### 2. AI 员工，融入你的业务系統
不同于停留在演示层面的 AI，NocoBase 让你能够将 AI 能力無缝集成到交互介面、业务流程和資料上下文中，让 AI 真正落地于企业场景。

- 定义 AI 员工，担任翻译员、分析员、调研员或助手等角色
- AI 与人工無缝协同于交互介面和业务流程
- 确保 AI 的使用符合企业的安全、透明和定制化需求

![AI-employee](https://static-docs.nocobase.com/ai-employee-home.png)

### 3. 所见即所得，极易上手
NocoBase 能够开发複雜而独特的业务系統，但使用体验却簡單直观。

- 一鍵切换使用模式与配置模式
- 頁面即画布，可随意拖曳区块和操作，像 Notion 一样搭建介面
- 配置模式面向普通使用者设计，而非仅限程序员

![wysiwyg](https://static-docs.nocobase.com/wysiwyg.gif)

### 4. 一切皆 外掛，为擴充而生
仅仅堆叠無代码功能，永远無法覆盖所有业务场景。NocoBase 基于 外掛化微内核架构，为擴充而设计。

- 所有功能都是外掛，類別似于 WordPress
- 外掛安裝即用
- 頁面、区块、操作、API、資料源等都可以通過外掛擴充
  
![plugins](https://static-docs.nocobase.com/plugins.png)

## 安裝

NocoBase 支持三种安裝方式：

- <a target="_blank" href="https://docs-cn.nocobase.com/welcome/getting-started/installation/docker-compose">Docker 安裝（推薦）</a>

   适合無代码场景，不需要写代码。升級時，下載最新镜像并重新啟動即可。

- <a target="_blank" href="https://docs-cn.nocobase.com/welcome/getting-started/installation/create-nocobase-app">create-nocobase-app 安裝</a>

   專案的业务代码完全独立，支持低代码开发。

- <a target="_blank" href="https://docs-cn.nocobase.com/welcome/getting-started/installation/git-clone">Git 源码安裝</a>

   如果你想体验最新未發布版本，或者想参与贡献，需要在源码上进行修改、除錯，建議選擇这种安裝方式，对开发技术水平要求较高，如果代码有更新，可以走 git 流程拉取最新代码。
